# C++-Native System Observation, Inventory & Discovery System

HARD INVARIANTS

- The project is Rebuntu. There is one Rebuntu.
- Rebuntu is C++-native.
- C++ owns authoritative deterministic runtime, state, observation, discovery, inventory semantics, control, coordination, policy/security enforcement boundaries, native OS integration, IPC, execution, verification, reconciliation and recovery.
- Python is allowed only at explicit, narrow, justified semantic/ML/research/testing/development boundaries.
- Do not recreate Python system scanners, inventory managers, hardware managers, process/service discovery engines or host-fact databases underneath C++.
- Architecture defines source ownership; language does not define architecture.
- Search and understand the repository before implementing.
- Extend/refactor/compose existing owners before adding parallel structures.
- Observation != inference.
- Observation != recommendation.
- Observation != recovery.
- Inventory != authority.
- Cache != authority.
- Name != identity.
- Path != identity.
- PID != durable process identity.
- GPU index != durable GPU identity.
- Mount path != durable storage identity.
- IP address != durable node/interface identity.
- Missing evidence != absence.
- Incomplete discovery != no match.
- UNKNOWN != PASS.
- DATA != CONTROL.
- MODEL OUTPUT != FACT.
- CONTEXT != AUTHORITY.
- BEFORE != CAUSED_BY.
- Use runtime discovery rather than hard-coded workstation topology.
- Native Linux sources remain authoritative for the state they own.
- Prefer native interfaces such as procfs, sysfs, udev, systemd D-Bus, netlink and established native libraries over parsing human CLI output.
- Providers provide mechanisms, not policy or authorization.
- No arbitrary shell control path.
- No destructive host/Git/filesystem cleanup.
- No giant SystemScanner, InventoryManager, HardwareManager, GlobalContext or universal mutable inventory database.
- Discovery must be bounded, cancellable and freshness-aware.
- Migrate callers recursively to a fixed point when ownership changes.
