configuration separate from system truth and execution policy. Preserve a restrained default Rebuntu interface
and avoid plugin/framework complexity without demonstrated need.

- Reuse, extend, migrate and refactor existing capabilities before creating new ones.
- Do not duplicate system-management logic inside the panel.
- Keep presentation separate from domain/control/execution logic.

- No destructive host action by default.
- Consequential mutations require explicit authorization and deterministic validation.
- Verify postconditions after execution.
- Preserve recovery paths and known-good state.
- Add/update tests and documentation for all material behavior.

## Completion Evidence

- repository areas inspected;
- existing capabilities reused;
- files created/modified/migrated;
- tests added/updated and their results;
- safety/authorization implications;
- remaining gaps or UNKNOWNs.
