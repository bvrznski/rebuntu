# Phase 28: Development Environment Management

This directory uses the normalized Rebuntu phase layout. Original prompt bodies are preserved under `prompts/`.

## Layout

- `prompts/` — implementation specifications for this phase.
- `INDEX.md` — ordered prompt inventory.
- `manifest.json` — machine-readable inventory with SHA-256 hashes.
- `PROMPT_STATS.txt` — phase statistics.
- `architecture/` — phase-level implementation and authority notes.
- `AGENT_HANDOFF.md` — execution rules for an implementation agent.

The prompts are implementation specifications: satisfy their behavior, invariants, integration, testing, and acceptance requirements in production C++20 rather than reducing them to stubs or coverage markers.
