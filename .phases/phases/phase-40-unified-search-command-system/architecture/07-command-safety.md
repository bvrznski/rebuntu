# Command Safety

```text
discover command
      ↓
typed intent
      ↓
resolve target/arguments
      ↓
applicability + preconditions
      ↓
domain plan
      ↓
validate
      ↓
authorize
      ↓
execute
      ↓
verify
      ↓
Phase 39 record
```

Phase 40 must not introduce an escape hatch that turns arbitrary natural language or search text into privileged shell execution.
