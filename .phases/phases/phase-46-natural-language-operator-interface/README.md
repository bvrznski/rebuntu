# Rebuntu Phase 46 — Natural Language Operator Interface (`ask`)

Complete executable specification.

`ask` is Rebuntu's one-shot natural-language operator interface:

```text
ask <natural-language request>

ask
ask> <natural-language request>
```

The second form accepts one request and returns to the parent shell.

Canonical security path:

```text
operator text
    ↓
bounded trusted context + provenance
    ↓
BitNet / semantic IntentCandidate
    ↓
deterministic intent + referent resolution
    ↓
contextual legitimacy / suspicious-effect analysis
    ↓
policy + capability + authority
    ↓
clarify / require justification / optionally consult Gordon / deny
    ↓
typed Phase 40/45 plan
    ↓
validate → authorize → execute → verify → Phase 39 record
```

Hard rule: **natural language may broaden understanding, but never authority**.

Unexpected consequential use without sufficient justification relative to current state and policy must not execute merely because the requester technically possesses the underlying permission.
