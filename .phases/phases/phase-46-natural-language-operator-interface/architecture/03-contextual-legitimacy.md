# Contextual Legitimacy and Unexpected-Use Detection

Authorization alone is insufficient for semantic execution.

Evaluate whether a consequential request is expected and justified relative to current authoritative system state, operator/session context, active project/workflow, recent actions, known services/data flows, structural knowledge, temporal history and applicable policy.

A technically authorized but contextually anomalous request may require explanation, clarification, stronger confirmation, advisory analysis, or denial.

Unexpected consequential use without sufficient contextual justification must not execute automatically.
