# Phase 45 Integration

Resolved actionable requests become typed Phase 40/45 candidate intents/plans.

Canonical path:
operator text → safe context → BitNet IntentCandidate → deterministic resolution → contextual legitimacy → policy/safety → clarification/advisory consultation if needed → typed Phase 45 plan → validation → authorization → execution → verification → Phase 39 record.

There is no direct `ask` → shell path.
