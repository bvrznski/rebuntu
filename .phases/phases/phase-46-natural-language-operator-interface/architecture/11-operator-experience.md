# Operator Experience

`ask` should feel lightweight while remaining explicit about consequential behavior.

Read-only questions may answer directly with evidence. Ambiguous requests ask concise clarification. Unexpected consequential requests explain why more justification is required. Plans can be previewed before authorization.

Bare `ask` displays a single minimal `ask>` prompt, accepts one request, processes it, and returns to the parent shell unless a future explicitly selected conversational mode is introduced.
