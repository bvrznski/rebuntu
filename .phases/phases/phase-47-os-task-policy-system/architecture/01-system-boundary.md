# Phase 47 — OS Task Policy System

Phase 47 establishes a unified policy system for tasks that affect, inspect, schedule, automate, or reason about the operating system.

An OS task is a typed goal-bearing unit of work with requester, context, scope, capabilities, authority requirements, constraints, risk, data-flow effects, resources, lifecycle, verification and audit semantics.

Phase 47 owns task-policy evaluation and policy composition. It does not replace Phase 45 execution authority, Phase 41 workflow orchestration, domain owners, or Phase 46 natural-language interpretation.
