# Rebuntu Visual Language

Create a coherent workstation/operator visual system: dense when useful, calm, legible, keyboard-friendly and compatible with Rebuntu's retro-tech character without sacrificing modern usability.

ASCII/terminal-inspired motifs may be used as a design language, but must not reduce accessibility or turn the GUI into a novelty terminal imitation.

Typography and iconography must use redistributable/system-available assets; never bundle user font files unless licensing and explicit inclusion are established.
