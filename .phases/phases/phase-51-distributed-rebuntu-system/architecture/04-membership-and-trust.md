# Membership and Trust Boundary

Phase 51 assumes one administrative trust domain but must not equate connectivity with trust.

Membership establishment, node admission, removal, quarantine, credential rotation and revocation are explicit state transitions.

Authentication establishes identity. Membership establishes participation. Policy establishes permission. Execution authorization remains separate.

Phase 52 may later add peer association across autonomous systems; Phase 53 may add federation. Do not prematurely collapse those models into Phase 51.
