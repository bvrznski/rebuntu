## Non-negotiable invariants

- THIS PROJECT IS REBUNTU; there is exactly one Rebuntu architecture.
- REBUNTU IS C++-NATIVE.
- Phase 55 extends and composes Phases 0–54; it does not create a second control plane.
- GOAL != COMMAND.
- GOAL != PLAN.
- PLAN != AUTHORIZATION.
- PLAN != EXECUTION.
- PREREQUISITE GRAPH != PLAN.
- MODEL-GENERATED PLAN != AUTHORITY.
- EXPECTED EFFECT != OBSERVED FACT.
- PREDICTED STATE != OBSERVED STATE.
- SIMULATION RESULT != EXECUTION RESULT.
- PLAN VALIDATION != AUTHORIZATION.
- Phase 45 remains the execution/control-plane authority.
- Phase 47 remains task-policy authority.
- Phase 53 mandatory security remains non-bypassable.
- Phase 54 capabilities/affordances inform planning but do not authorize it.
- Phase 48 context supplies evidence/relevance, never authority.
- Phase 42 graph structure does not imply causal truth.
- Phase 39 ordering does not imply causality.
- Phase 50 platform capability does not imply permission.
- Phase 51/52 reachability/association/trust does not imply remote execution authority.
- DATA != CONTROL.
- MODEL OUTPUT != AUTHORITY.
- CONTEXT != AUTHORITY.
- TRUST != EXECUTION AUTHORITY.
- PRIVILEGE != INTEGRITY.
- AUTHENTICATION != AUTHORIZATION.
- UNKNOWN != PASS.
- Missing evidence does not prove a precondition.
- Stale evidence cannot validate a current plan.
- Every consequential plan must be revalidated before execution and as required between steps.
- Execution feedback returns to observation/verification; planner does not assume expected effects occurred.
- Deviation from expected state may require stop, repair or replanning.
- Cancellation != rollback.
- Compensation != rollback.
- Retry != replay permission.
- Timeout/crash/interruption does not prove no effect.
- Never blindly replay an ambiguous step.
- No exactly-once fiction.
- Idempotency is explicit and scoped.
- Plans use typed operations, exact targets and strong identities.
- Name/path/PID/GPU index/remote address are not automatically durable identities.
- Planning search is bounded by depth, breadth, time, memory and candidate count.
- Dependency/prerequisite graphs require cycle detection.
- Parallelism is allowed only when dependencies/resources/effects do not conflict.
- Cost/risk metadata may compare technical properties but cannot replace policy/security authorization.
- Irreversible boundaries are explicit and visible.
- Plan simulation is conservative and uncertainty-preserving.
- Semantic/LLM services may propose goals, decompositions, candidates or explanations only.
- Deterministic C++ validation must accept/reject semantic proposals before canonical use.
- Python cannot own authoritative planner state, plan validation or execution control.
- Shell cannot be the plan representation or execution architecture.
- No system(), popen(), sh -c or bash -c as canonical plan execution.
- No giant PlannerManager/GoalManager/Orchestrator god-object.
- Use C++20, RAII, strong types, explicit ownership and bounded concurrency.
- No raw owning pointers.
- No unbounded queues, recursion, graph expansion, retries or candidate retention.
- Plan persistence/cache/history are not live authority.
- SecretMaterial never enters generic plan graphs/logs/prompts.
- Production planning code must be linked and runtime-reachable.
- Caller migration reaches a fixed point before duplicate planner logic retires.
- Do not mutate the host merely to test planning; use simulation/contained fixtures.
- Documentation must state actual planning guarantees and uncertainty.
- Rebuntu evolves through aggregational morphing, not parallel bolt-ons.
