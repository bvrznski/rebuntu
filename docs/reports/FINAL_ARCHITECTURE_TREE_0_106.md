# Final Architecture Tree Materialization — Phases 0–106

The runtime/source tree is consolidated by responsibility rather than phase number.

- `.phases/PHASES` remains specification and provenance.
- `src/rebuntu` is the target system architecture.
- Native Linux facilities remain authoritative.
- `providers/linux` contains narrow typed boundaries only.
- Domain branches contain Rebuntu semantics, desired state, evidence, verification and reconciliation rather than replicas of Linux mechanisms.
- Cross-domain capabilities live in semantics, observation, knowledge, planning, control, security, automation and operator layers.

Generated target tree: 349 responsibility components, each with an explicit contract and architectural responsibility note.
